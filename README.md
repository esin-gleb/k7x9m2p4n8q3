# АиР — PWA-тренажёр

## Публикация на GitHub Pages

1. Создай публичный репозиторий на github.com.
2. Add file → Upload files → перетащи все файлы и папки (включая `data/` и `icons/`) → Commit.
3. Settings → Pages → Deploy from a branch → main → root → Save.
4. Через 1-2 мин появится URL вида `https://логин.github.io/repo/`.
5. Открой URL на телефоне → Chrome (⋮) → Установить приложение.

## Админский режим (кнопка QR)

Кнопка «📤 QR» на дашборде видна только на устройствах, где активирован админский режим.

**Активация:** открой один раз URL с параметром:
```
https://логин.github.io/repo/?admin=b275e48a41c9df356b7e404927eb70b8
```
Флаг сохранится в localStorage, кнопка появится и останется. Параметр из адресной строки автоматически удаляется — токен нигде не отображается.

**Деактивация:** открой URL с `?admin=0` — флаг сбросится.

Токен спрятан только в исходнике `index.html` — он не «настоящая» защита, а способ не показывать кнопку случайным пользователям.

## Пороги (Московский врач)

- 🟢 ≥80% — сдано
- 🟡 70-79% — на грани
- 🔴 <70% — не сдано

## Как добавить новую тему

1. Создай `data/xxx.json` с массивом задач.
2. Добавь запись в `data/topics.json`.
3. В `sw.js`: добавь путь в `ASSETS`, увеличь версию `CACHE = 'air-vN'`.
4. Commit → GitHub Pages обновится.
