# Тесты АиР — PWA

Тренажёр к экзамену «Московский врач» по анестезиологии-реаниматологии.

## Публикация

1. GitHub → New public repository.
2. Add file → Upload files → перетащи всё содержимое архива → Commit.
3. Settings → Pages → Deploy from branch main → root → Save.
4. Через минуту откроется URL.

## Админ-режим (QR-кнопка)

Открой один раз на каждом своём устройстве:
```
https://логин.github.io/repo/?admin=b275e48a41c9df356b7e404927eb70b8
```
Токен сохранится в localStorage, из URL удалится автоматически.
Отключение: `?admin=0`.

## Логика прогресса

- Каждая задача имеет статус: **освоена** / **не освоена**. Изначально все не освоены.
- **Зубрёжка** показывает только не освоенные. Кнопка «Помню» → отмечает как освоенную, «Не помню» → возвращает в не освоенные.
- **Тест** идёт по всем задачам темы. Правильный ответ → освоена, неправильный или пропуск → возвращена в не освоенные.
- **Экзамен** — 100 случайных задач из всех тем. То же правило: правильный → освоена, ошибка/пропуск → назад в не освоенные.
- **Плитка на дашборде** окрашивается по последнему тесту или экзамену (что позже). Порог 80%: 🟢 сдано, 🔴 не сдано.
- Экзамен обновляет цвет плитки темы только если по этой теме попалось больше 5 вопросов.

## Пороги

- 🟢 ≥80% — сдано
- 🔴 <80% — не сдано

Жёлтой градации нет.

## Добавление темы

1. `data/xxx.json` — массив задач `[{id,cram_key,cram_q,scen,q,opts,correct}, ...]`.
2. `data/topics.json` — добавить `{id,name,emoji,count}`.
3. `sw.js` — добавить путь в ASSETS, поднять версию CACHE.
