# АиР — PWA-тренажёр

Локальное веб-приложение для подготовки к экзамену «Московский врач» по анестезиологии-реаниматологии. Работает офлайн, устанавливается на телефон как обычное приложение.

## Публикация на GitHub Pages (5 минут)

1. Открой https://github.com → **New repository** → назови, например, `air-exam` → **Public** → Create.
2. На странице пустого репозитория нажми **uploading an existing file** → перетащи в окно **все файлы и папки** из этого архива (index.html, topic.html, manifest.webmanifest, sw.js, папки `data/` и `icons/`, этот README). → Commit changes.
3. Settings → **Pages** (в левом меню) → Source: **Deploy from a branch** → Branch: **main** / **/(root)** → Save.
4. Подожди 1-2 минуты. На той же странице появится URL вида `https://твой-логин.github.io/air-exam/`.
5. Открой этот URL на телефоне в Chrome → меню (⋮) → **Установить приложение** (или «Добавить на главный экран»).
6. Готово. На главном экране появится иконка «АиР». Приложение работает офлайн.

## Как добавить новую тему

1. В папке `data/` создай `xxx.json` — массив задач в формате:
   ```json
   [{"id":"...","cram_key":"...","cram_q":"...","scen":"...","q":"...","opts":["...","..."],"correct":"..."}]
   ```
2. В `data/topics.json` добавь запись `{"id":"xxx","name":"...","emoji":"…","count":N}`.
3. В `sw.js` в массив ASSETS добавь `'./data/xxx.json'`.
4. Обнови номер версии кэша в `sw.js` (`const CACHE = 'air-v2'`) — иначе установленное приложение не увидит новую тему.
5. Закоммить изменения в GitHub — обновление раскатится автоматически.

## Пороги (Московский врач)

- 🟢 ≥80% — сдано
- 🟡 70-79% — на грани
- 🔴 <70% — не сдано

## Прогресс

Хранится локально в браузере (localStorage). При очистке кэша Chrome — обнуляется. Синхронизации между устройствами нет.
